\## Обоснование приоритетов



\- \*\*Must have:\*\* без этих историй приложение не решает главную проблему заказчика (отчёт за час вместо 2–3 дней). Нужны данные (US-01), показатели (US-02), отчёт (US-04) и разграничение доступа (US-06), которое требует заказчик.

\- \*\*Should have:\*\* важно, но запуск не блокирует. Результаты по отделам, сохранение в Excel и личный кабинет менеджера удобны, а на старте отчёт можно смотреть на экране.

\- \*\*Could have:\*\* журнал загрузок желателен для поиска ошибок, но без него система работает.

\- \*\*Won't have:\*\* автозагрузка из учётной системы не входит в релиз, потому что ограничения проекта исключают интеграцию (данные поступают только файлами Excel и CSV). История остаётся в backlog на будущее.
