\# Описание ключевых Use Case



\## Загрузка выгрузки продаж



| Поле | Значение |

|---|---|

| Название | Загрузка выгрузки продаж |

| Актор | Менеджер по продажам |

| Предусловие | Менеджер вошёл в систему, у него есть файл .xlsx или .csv с колонками «Дата», «Менеджер», «Выручка», «Затраты» |

| Основной поток | 1. Менеджер открывает раздел загрузки. 2. Выбирает файл. 3. Нажимает «Загрузить». 4. Система проверяет структуру файла. 5. Система сохраняет данные. 6. Система показывает число загруженных строк |

| Альтернативный поток | Если нет колонки «Выручка» или в ней текст вместо чисел, система не сохраняет данные и указывает проблемную колонку или строку |

| Постусловие | Данные сохранены и учитываются в показателях, запись о загрузке попала в журнал |



\## Формирование отчёта за период



| Поле | Значение |

|---|---|

| Название | Формирование отчёта за период |

| Актор | Аналитик |

| Предусловие | Аналитик вошёл в систему, данные о продажах загружены |

| Основной поток | 1. Аналитик открывает раздел «Отчёты». 2. Выбирает период. 3. Нажимает «Сформировать». 4. Система строит таблицу выручки по месяцам с итогом. 5. Аналитик просматривает отчёт |

| Альтернативный поток | Если за период нет данных, система показывает сообщение «За выбранный период данных нет», отчёт не создаётся |

| Постусловие | Отчёт построен и доступен для сохранения в Excel |
